## Open data

`site/datos/` contains the public version of a sleep-disorder prevalence study
(Oviedo Sleep Questionnaire, N = 57 university students, Trujillo, Peru, 2026)
and the scripts that produce every figure reported.

The public files are generated by `preparar_datos_publicos.py`, which is itself
published so the anonymisation can be audited: free text written by participants,
scan file names and dates are removed, and case codes are randomly reassigned
without keeping the correspondence. Item responses, scores, diagnoses and coding
notes are kept unchanged. Raw questionnaires never enter this repository.
